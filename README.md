# sms-demo

School management system **demo** instance — built on Laravel 12 (single-school mode). Separate from the live Dreams Academy project (`dream.test` / `dream` database).

## Quick start

See [SETUP.md](SETUP.md) for local (Laragon) and production deployment instructions.

## Default super admin (after seeding)

When `APP_DEMO=false`:

| Field    | Value |
|----------|--------|
| Email    | `superadmin@<APP_DOMAIN>` (e.g. `superadmin@smsdemo.test` locally) |
| Password | `123456` |

Change the password immediately after first login.
